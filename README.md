# goit-js-hw-12

## JavaScript Homework 12

This project was created using **Vite**.

## Task

### 🖼️ Image Search

A web application for searching images using the **Pixabay API**.

The project includes:

- 🔎 Image search
- 📄 Pagination with **Load more**
- ⏳ Loading indicator
- 🖼️ Image gallery
- 🔍 Full-size image preview using **SimpleLightbox**
- 📜 Smooth page scrolling
- 🔔 User notifications using **iziToast**
- ⚡ Asynchronous requests using `async/await`

## Technologies

- HTML
- CSS
- JavaScript
- Vite
- Axios
- Pixabay API
- SimpleLightbox
- iziToast
